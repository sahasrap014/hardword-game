# Hard Word Guessing Game

A simple 4-letter word guessing game built using Python.

The program randomly selects a 4-letter word from a predefined list. The player has to guess the word and receives feedback about the letters in the guess.

## How It Works
The program randomly selects a 4-letter word.
The player enters a 4-letter word.
The program checks the guessed word against the selected word.
It displays:
The number of letters in the correct position.
The number of letters that are present but in the wrong position.
The player continues guessing until the correct word is found.
When the correct word is guessed, the program displays YOU WON!
